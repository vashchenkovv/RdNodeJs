- Реализован загрузка изображений для сущностей User и Product

- Клиент предает на сервер данные загружаемого файла (FileAccess, sizeBytes, avatar | product-imageы)
- - сервер создает запись в бд и запрашивает файловый сервер сгенерировать ссылку для загрузки
- - сервер возвращает информацию для загрузки файла (file id и URL для закачки файла)
- - клиент заливает файл на файловый сервер, затем делает запрос на наш сервер информируя что фай был загружен (запрос содержит ид файла)
- - сервер находит мета данные файла в БД и меняет статус на ready

- Для загрузки аватрарки пользователь должен быть зарегистрирован. Доступ к изображению разрешен пользователя который загрузил изображение (сравниваем ид текущего пользователя и ид пользователя который загрузил файл). Так же аватарки могут смотреть сотрудники, доступ дается для определенных групп пользователей. Загружать изображения для товаров могут только сотрудники компании (определенные группы пользователей) которым разрешено это делать (есть scope file:upload). А доступ к изображениям товара есть у всех

- В учебных целях используется хранилище MinIO. URL для доступа к файлу: {адрес сервера}/{имя бакета}/{тип файла (аватар, картинка товара)}/{ид пользователя}/{текущая дата - uuid}.{тип файла}
